# Version 0.1.16 (2026-07-18)

### Features
- **Enum Filtering**: Added support for filtering by Enum fields in `@FilterField`. Enum filters are generated as a `Set` of Enum constants, allowing for multiple-selection filtering (using the `IN` operator).

### Bug Fixes
- **One-to-Many Unlinking**: Fixed an issue where unlinking a child entity from its parent in a one-to-many relationship (where the child owns the relationship) was not persisted. An explicit save operation is now performed for the child entity after clearing the parent reference.

### Improvements
- **Modernized Test Syntax**: Updated integration tests to use Java 21 `List.getFirst()` method.

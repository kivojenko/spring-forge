# Version 0.1.17 (2026-08-07)

### Features
- **Custom Repository Interfaces**: Added `interfaces` attribute to `@WithJpaRepository`. This allows generated repositories to extend one or more custom interfaces, enabling the integration of custom repository methods.
- **Inheritance Hierarchy Filtering**: Introduced support for filtering entities within inheritance hierarchies (both `SINGLE_TABLE` and `JOINED` strategies). The generator now automatically handles discriminator columns and produces appropriate filtering logic for sub-types.
- **Required Filter Fields**: Added a `required` parameter to the `@FilterField` annotation. When enabled, the generated filter DTOs will include validation annotations (such as `@NotNull`), and the filtering logic will enforce the presence of these fields.
- **Match Null Values in Filters**: Added the `orNull` parameter to `@FilterField`. This allows filters to match records where the targeted field is `null` in the database, in addition to matching the provided filter value.

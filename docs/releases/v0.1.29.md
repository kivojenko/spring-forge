# Version 0.1.29 (2026-10-05)

### Features
- **Jackson JSON View Support (`view` attribute)**:
  - Added `view` attribute (`Class<?> view() default Void.class`) to `@WithRestController`, `@WithEndpoints`, and `@WithGetEndpoint`.
  - When specified on `@WithRestController`, applies Jackson `@JsonView(<View>.class)` to the generated controller class and standard CRUD endpoints (`findAll`, `getById`, `update`, `patch`, `getOrCreate`).
  - When specified on `@WithEndpoints` or `@WithGetEndpoint`, applies `@JsonView(<View>.class)` directly to the generated association or custom GET endpoint methods.
  - Association endpoints automatically fall back to the controller's configured JSON view if no endpoint-specific view is specified.
  - Enables fine-grained serialization filtering across entity CRUD operations and relationship traversal endpoints.

### Documentation
- README: documented `view` attribute on `@WithRestController`, `@WithEndpoints`, and `@WithGetEndpoint`.

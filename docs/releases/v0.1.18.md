# Version 0.1.18 (2026-08-07)

### Features
- **Generic Repository Interfaces**: Added support for automatic parameterization of generic interfaces in `@WithJpaRepository(interfaces = ...)`. If an interface has exactly one type parameter, it will be automatically parameterized with the entity type.
  - Allows creating reusable repository patterns like `WithNameTranslation<T>`.
  - Simplifies integration with custom repository logic.

# Version 0.1.22 (2026-08-13)

### Features
- PATCH support for generated controllers/services:
  - Added `@PatchMapping` in controllers and `ForgeService#patch(ID, Map<String, Object>)` to apply partial updates to existing entities.
  - Ignores `id`, performs basic type coercion (numbers, booleans, enums, strings), calls `fixParameters`, and persists changes.
- Add-new association endpoints generated for `@WithEndpoints`:
  - ManyToOne: POST create-and-link of the target entity to the owning side.
  - ManyToMany: POST create-and-attach of a new target entity to the collection.
  - OneToOne: POST now supported for entity fields in addition to previously added support for `@Embedded` fields.

# Version 0.1.24 (2026-08-19)

### Features
- **Nested Field Paths in `@GetOrCreate` Operations**:
  - Added support for dotted nested field paths (e.g., `@GetOrCreate(field = "country.code")`) across controller, service, and repository code generation.
  - Generates safe query method names and request parameters for nested paths in repository, service, and REST controller layers.
  - Enhanced entity model generation to support instantiating entities with relationship ID references.
- **Jackson-Powered PATCH Deserialization and In-Place Collection Merging**:
  - Replaced manual field type coercion in `ForgeService#patch` with Jackson-based deserialization using field generic type information, supporting complex and nested objects.
  - Implemented in-place collection merging (`clear()` and `addAll()`) for collection fields during PATCH operations to maintain JPA/Hibernate collection management and `orphanRemoval` behavior.
  - Introduced optional `fixPatch(E entity)` hook in `ForgeService` for post-PATCH entity adjustments prior to saving.
- **QueryDSL Filtering Enhancements**:
  - Enhanced filtering resolution to support nested field paths and collection associations using `.any()` predicates.

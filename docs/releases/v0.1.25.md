# Version 0.1.25 (2026-08-26)

### Features
- **Repeatable `@FilterField` Annotations**:
  - Introduced container annotation `FilterFields` and marked `@FilterField` with `@Repeatable(FilterFields.class)` to allow multiple filter definitions on a single entity field.
  - Updated `FilterFieldModelFactory` to process repeated annotations via `getAnnotationsByType`.
  - Added support in `JpaEntityModel#toPredicateMethod` to OR-combine QueryDSL expressions when multiple filter fields share the same exposed parameter name.
- **Collection Size Filtering with `IterableMatchMode.AMOUNT`**:
  - Added `IterableMatchMode.AMOUNT` enum constant for filtering collections based on item count.
  - Maps collection size filters to `.size()` QueryDSL paths and exposes integer-based exact and range query parameters (`<name>`, `min<Name>`, `max<Name>`).
- **Slash Support in Entity ID Paths (`allowSlashes`)**:
  - Added `allowSlashes` attribute to `@WithRestController` and compile-time configuration support (`controller.allowSlashes`, `controller.allow-slashes`, `allowSlashes`).
  - Updated `ControllerGenerator` to use Spring Web `{*id}` URI template syntax on generated controller routes (GET, HEAD, PUT, PATCH, DELETE, and association sub-resources) to support IDs containing forward slashes.

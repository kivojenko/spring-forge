# Version 0.1.20 (2026-08-08)

### Features
- **Dynamic ID Naming**: The generated controllers and their association endpoints now use the actual name of the entity's ID field (e.g., `{code}` for a `Country` entity with a `code` field as its primary key) instead of hardcoded `{baseId}` or `{id}`. This improves API consistency and avoids parameter name collisions in nested endpoints.
- **Inherited Filter Fields**: `@FilterField` annotations on superclasses (both `@Entity` and `@MappedSuperclass`) are now correctly recognized and included in the generated QueryDSL filter classes for subclasses. This allows for unified filtering across entity hierarchies.

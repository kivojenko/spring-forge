# Version 0.1.23 (2026-08-17)

### Features
- **Abstract Entity Support**:
  - Introduced `ForgeAbstractController` as the base controller for abstract JPA entities, omitting entity creation endpoints (e.g. POST `/entities`).
  - Automatically skipped generation of "add new" association endpoints and `get-or-create` endpoints when the target or base entity is abstract.
  - Enhanced `EndpointRelationResolver` to resolve inherited association endpoints across the entity superclass hierarchy.
- **Improved AOP Persistence Aspect Lifecycle**:
  - Refined `ForgePersistenceAspect` pointcuts for association addition to match `addNew*` and `addExisting*` methods.
  - Refined association removal pointcuts to match `remove*` and `unlink*` methods.
  - Added `@AfterReturning` pointcut for `ForgeService#patch` (`onAfterPatch`) to trigger `afterUpdate` hooks on partial updates.
- **Collection Type Conversion in PATCH Operations**:
  - Added support for collection type conversion in `ForgeService#patch` when converting between `Set` and `List` collection types (including `HashSet`, `LinkedHashSet`, `TreeSet`, `ArrayList`, `LinkedList`, array inputs, and `Iterable`s).
